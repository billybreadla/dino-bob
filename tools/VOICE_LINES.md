# Penny's Voice Lines — recording guide

The game calls `AUDIO.voice(name)` at four big moments. Drop recordings in
`audio/` with these EXACT filenames (lowercase, underscores):

| Filename            | Moment                        | Suggested script (Penny-style) |
|---------------------|-------------------------------|--------------------------------|
| `boss_appear.mp3`   | a boss rises from the ground  | "ROAR! The Moonstone King awakes!" |
| `boss_down.mp3`     | boss defeated                 | "BOSS DOWN! Best archer EVER!" |
| `stage_clear.mp3`   | adventure stage won           | "Stage complete! Stars for the map!" |
| `new_best.mp3`      | brand-new high score          | "NEW BEST SCORE! Confetti! CONFETTI!" |

## How to record (Voice Memos, iPad/iPhone)

1. Open **Voice Memos**, hold the device close to the speaker (that's you,
   Penny!), and record each line 2-3 times. Keep each one under ~3 seconds.
2. Tap the recording -> share -> **Save to Files**, and name it exactly as
   above (Voice Memos saves `.m4a` -- that works too! The game tries `.mp3`
   first, then `.m4a`).
3. Put both/any into the `audio/` folder of the game.
4. Reload the game page. Lines play fire-and-forget: if a file is missing the
   game stays silent (never an error), so you can add them one at a time.

## Tips

- Big energy! Yell it like the boss can hear you.
- Quiet room, no fan/TV. The game ducks nothing, so short + punchy is best.
- One line per file. Giggles at the end of a take are allowed (encouraged).
- If a take has a long silence at the start, trim it in Voice Memos
  (tap the recording -> Edit -> trim) so the shout fires instantly.
